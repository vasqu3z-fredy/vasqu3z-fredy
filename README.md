## 📌 Proyectos Destacados

### 🧭 Mapa Interactivo del Campus
Sistema de navegación indoor tipo Google Maps, usando QR y coordenadas desde una base de datos. Implementado en Angular + Mapbox, con rutas geodésicas y actualización en tiempo real desde GPS del móvil.

### 🎙️ App de Grabación por ID de Estudiante
Aplicación web que permite grabaciones con temporizador global (20 min) y temporizadores individuales. Frontend responsivo con Bootstrap y lógica de grabación controlada por ID del alumno.
